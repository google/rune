# Rune extensions

A Rune extension could be a package users can install into their Rune
environment to add new capabilities to the compiler, such as DSLs.  It would be
cool to have a website with Rune extensions much like Chrome's extensions
website.  Users could not only write extensions but share them easily.  An
extension consists of:

* A syntax file of additinal rules or the Rune parserr.
* A set of Rune files which must contain transofrmers for all new rules.

The syntax for rules will be extended to bind transformers to rules:

```
statement: "printHello" nl+ => HelloStatement
```

Handlers would be called on AST nodes bottom-up and can replace their nodes
with whatever they like, such as nodes that are handled by other transformers,
enabling recursive transformation.  For example, this recursive handler would
compute n factorial:

```
// Syntax file.

prefixExpr: "fact" INTEGER => FactorialExpr
```

```
// Transoformer file.

// Handles "fact n" syntax for constant n.
transformer FactorialExpr(node: Node) {
  // We need some good node replacement syntax... implement with an extension?
  value = node.first.value
  // Call replaceNode transformer that replaces node with nodes returned by
  // parse starting at "expr" rule.
  macros.replaceNode(node, "expr", "%d * fact %d" % (value, value - 1))
}
```

A fun extension would be one that replaces a text description of a function
with the code generated by an LLM.   I'm not sure why that might be useful, but it
would be cool.
